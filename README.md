# ⚽ كشّاف: منصة تحليل وتقييم اللاعبين (نسخة تجريبية خاصة)

تحلل اللاعب من بيانات مباريات حقيقية، ثم يجمع الذكاء الاصطناعي (DeepSeek) آراء المحللين والجمهور والتقارير الفنية وتقارير المباريات والإحصاءات، ويدمجها كلها في تقرير كشفي بالعربي.

> ⚠️ للاستخدام الشخصي والتجربة فقط. البيانات مسحوبة من مواقع عامة وغير مرخّصة للاستخدام التجاري.

## التشغيل

```powershell
pip install -r requirements.txt
python -m streamlit run app.py
```

ثم افتح http://localhost:8501

## ربط DeepSeek (مرة واحدة)

عندك طريقتان، وبعدها يشتغل المفتاح تلقائيًا في كل مرة:

1. **من داخل الموقع:** أول ما تفتحه تظهر خانة "ربط DeepSeek". تضع المفتاح وتضغط "حفظ وربط"، وينحفظ في ملف `.env` على جهازك.
2. **يدويًا:** انسخ `.env.example` باسم `.env` واكتب فيه `DEEPSEEK_API_KEY=sk-...`

المفتاح يبقى على جهازك أو على الخادم فقط، وما يوصل لمتصفح الزائر.

## الأقسام

### تحليل لاعب
| الصفحة | المحتوى |
|---|---|
| **الملخص** | بطاقة كشّاف، هوية اللاعب مبنية على أقوى ما يميزه في الأرقام، أبرز الإيجابيات والسلبيات، نوعية الفرق المناسبة، التوافق مع المدرب، بدلاء بنفس الأسلوب (اضغط على أي بديل لتحليله)، المخاطر |
| أسلوب اللعب | كيف يلعب والدور الأنسب، المراكز اللي لعبها فعلًا، سمات اللعب، الأرقام مقارنة بلاعبي مركزه |
| المدرب والنادي | أساليب المدرب، وما يطلبه مقابل مستوى اللاعب، والحكم، وهوية النادي وأهدافه |
| المسيرة والثبات | التقييم موسمًا بموسم، ومراحل المسيرة وأسبابها، ودرجة الثبات |
| القيمة والبدلاء | سعر الشراء والراتب العادلان، والقيمة التسويقية، وكل البدلاء مع التصفية |
| التقرير PDF | ملف الملخص، أو التقرير الكامل (كل شيء ما عدا المصادر) |

### البحث بالمواصفات
تكتب وصف اللاعب اللي تحتاجه، مثلًا: "لاعب وسط مجاني يجيد الكرات الطويلة من دوري روشن". النتائج تطلع مرتبة من الأنسب للأقل بنسبة مطابقة، ولكل لاعب: سعر الشراء المتوقع، أو "مجاني/ينتهي عقده"، والراتب المتوقع، وسبب الترشيح. وتقدر تعدّل المعايير يدويًا.

### البدلاء بنفس الأسلوب
كل لاعب في قاعدة 4,000 لاعب (16 دوري) له بصمة من 14 مؤشر أسلوب لعب: صناعة الفرص، والكرات الطويلة، والتمرير، والمراوغة، والتسديد، والافتكاك، والاعتراض، والضغط... والبدلاء هم الأقرب في هذه البصمة (نسبة التشابه)، ثم الأفضل مستوى وسعرًا. للدوري الإنجليزي تُضاف بيانات تتبّع بدنية (المسافة، والانطلاقات السريعة، والسرعة القصوى).

### لغات البحث
العربية والإنجليزية دائمًا، ويُضاف تلقائيًا حتى 3 لغات حسب جنسية اللاعب والدوريات اللي لعب فيها (الفرنسية، الإسبانية، الإيطالية، الألمانية، البرتغالية، التركية، الهولندية). وتقدر تختارها يدويًا.

## ملاحظاتك كمتابع

في خانة البحث فيه "ملاحظاتك كمتابع للاعب". اكتب فيها اللي تشوفه بعينك وما تقيسه البيانات المجانية، مثل الركض والشدة. الذكاء الاصطناعي يدمجها مع الأرقام كمشاهدة كشاف، وينبهك إذا الأرقام تعارضها.

## كيف يبقى التحليل موضوعيًا؟

- الذكاء الاصطناعي يستلم **كل المعطيات**: إحصاءات الموسمين الأخيرين كاملة، وآخر 15 مباراة، والمسيرة، والانتقالات، والقيمة سنة بسنة، والإصابة الحالية، والبطولات، وترتيب الفريق، وسياق العمر وقوة الدوري، ثم مصادر الويب.
- ترتيب الثقة: بيانات المباريات أولًا، ثم تقارير المباريات والمحللين، ثم مواقع الإحصاء، ثم الجمهور (انطباع فقط).
- كل سمة لعب = متوسط بين رقم البيانات وتقدير الذكاء الاصطناعي، فما يقدر يبتعد كثير عن الأرقام.
- التعديل حسب العمر (المستوى الحالي وليس الذروة)، وقوة الدوري، وهيمنة الفريق.
- يذكر حدود التحليل ("ما لم تحسمه البيانات") ومستوى الثقة.

## مصادر البيانات

- **بيانات المباريات:** إحصاءات متقدمة لأكثر من 100 دوري منها دوري روشن، وتقييم كل مباراة، والمسيرة الكاملة (FotMob / Opta).
- **القيم والانتقالات:** Transfermarkt وSciSports.
- **xG:** Understat للدوريات الخمسة الكبرى.
- **بحث الويب:** آراء المحللين، وآراء الجمهور، والتقارير الفنية، وتقارير المباريات، والإحصاءات، والعقود، والإصابات، والسوشال ميديا، ومعلومات النادي والمدرب.

## حدود النسخة الحالية

- السرعة الحقيقية بالكيلومتر تحتاج بيانات تتبّع مدفوعة. هنا تُقدَّر من التقارير والتحليلات.
- الإحصاءات الدفاعية بالحجم تقل في فرق الاستحواذ، فنعطي وزنًا أكبر لنسب النجاح.
- تقدير النموذج المستقل للقيمة يطلع ضمن ±41% من قيمة السوق في نص الحالات، لذلك يُدمج مع قيمتي السوق.

## البنية

```
app.py                 الصفحات (ملخص + تفاصيل)
scout/report.py        تقرير PDF (تصميم للطباعة عبر Edge/Chrome)
scout/spec.py          البحث بالمواصفات (فهم الطلب، الترتيب، الأسعار)
ui_kit.py              التصميم: بطاقة كشّاف، الرادار، الحلقات، الأشرطة
.streamlit/config.toml الثيم
scout/
  data_tm.py           Transfermarkt
  data_fotmob.py       إحصاءات المباريات والمسيرة والمراكز
  data_understat.py    xG
  metrics.py           تحويل الإحصاءات إلى تقييمات 0-99
  career.py            المسيرة، التحولات، الثبات
  fit.py               المراكز والمنظومات
  valuation.py         القيمة والسعر والراتب
  pool.py              قاعدة 16 دوري: بصمة الأسلوب، البدلاء المشابهون، البحث بالمواصفات
  web.py               البحث في الويب (محللون، جمهور، تقارير، مباريات، نادي ومدرب)
  ai.py                DeepSeek (3 تحليلات متوازية: القدرات، الملخص، المسيرة والمدرب)
  settings.py          ربط المفتاح
  profile.py           يجمع كل ما سبق
```


## النشر على Hugging Face Spaces (مجاني)

```powershell
pip install huggingface_hub
hf auth login
python deploy.py USERNAME/kashaf-scout
```

بعدها من صفحة الـ Space ثم Settings ثم Variables and secrets أضف:
- `DEEPSEEK_API_KEY`: مفتاحك.
- `APP_PASSWORD`: كلمة مرور تعطيها للمهتمين.
- `DAILY_AI_LIMIT`: عدد التحليلات الذكية المسموح بها يوميًا (مثلًا 20) لحماية رصيدك.
